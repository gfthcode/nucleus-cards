# PokéCollector-style UI migration matrix

本次迁移只借鉴参考产品的信息架构、密度和交互模式，不复制其品牌、Logo、Pokemon 内容、素材或代码。NBA 内容、数据边界与现有业务逻辑保持不变。

| 旧功能 | 旧入口 / 路由 | 新 UI 位置 / 入口 | 状态 |
| --- | --- | --- | --- |
| 首页市场总览 | 首页 `/` | 首页锚点导航「总览」与分段仪表盘 | 已迁移 |
| 卡片搜索与筛选 | 市场 `/market` | 顶部全局搜索、市场筛选工具栏、快速筛选 chips | 已保留 |
| 球员档案 | 球员 `/players/[id]` | 球队与球员 `/teams` → 球员详情 | 已保留 |
| 球队列表 / 详情 | `/teams`, `/teams/[slug]` | 球队与球员导航、球队卡片网格 | 已保留 |
| 卡片详情 | `/cards/[id]` | 市场列表卡片点击、卡片详情页 | 已保留 |
| 收藏 / 持仓 | `/portfolio`, `/collections/demo` | 持仓导航、收藏集合页 | 已保留 |

## 统一交互验收

- 桌面端：固定侧栏 + 顶部搜索 + 页面内容区；所有主要操作保留 1–2 次点击内入口。
- 移动端：顶部搜索 + 底部五项导航；筛选和表格可横向滚动或折叠。
- 反馈：按钮、链接、筛选 chips、表格行均有 hover/focus/active 状态；空状态、加载状态、错误状态沿用现有组件。
- 可信度：演示数据、授权状态、来源和更新时间继续显式展示，未经授权的真实成交与图片不做事实性陈述。
