# 数据授权与合规状态

## 当前状态

当前仓库只内置明确标记的演示数据、CSV 人工导入流程和官方 API 适配器占位。没有实现网页爬虫，也没有绕过登录、验证码、付费墙或访问限制。

| 来源类型                    | 当前能力                       | 授权状态                     |
| --------------------------- | ------------------------------ | ---------------------------- |
| 本地演示                    | 在售、成交、球员事件、来源健康 | 仅用于产品演示               |
| eBay                        | Browse API 适配器占位          | 需要开发者账号与官方条款审核 |
| 卡淘 / 闲鱼                 | CSV、人工审核、接口占位        | 需要书面商业授权或官方 API   |
| Carousell HK / 香港卡店     | CSV、人工审核、接口占位        | 需要逐来源确认授权           |
| Goldin / Heritage / COMC 等 | 接口占位                       | 需要官方 API 或商业授权      |
| 用户/线下提交               | 校验后进入审核队列             | 永久标记社区或线下来源       |

## 接入前检查

1. 确认 API、导出或商业数据许可是否允许当前地区、缓存期限和再展示方式。
2. 保存来源、原始 URL、获取时间、授权状态、原币种和成交时点汇率。
3. 区分在售、真实成交、社区提交、平台认证成交和估算。
4. 建立删除/更正机制、访问审计、限流、错误退避和来源下线开关。
5. 对球员图片、卡图、联盟/球队/品牌标识另行取得版权或商标使用许可。
6. 中国内地正式服务需进行 ICP、个人信息保护、数据安全、跨境传输和算法/生成式 AI 适用性评估。

本说明是工程合规边界记录，不构成法律意见。
