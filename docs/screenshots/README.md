# 截图位置与规则

发布 GitHub 或产品介绍时，建议在本目录加入：

- `home-desktop.png`：1440×1000 首页。
- `market-desktop.png`：1440×1000 行情筛选。
- `card-detail-desktop.png`：1440×1000 卡片价格与证据。
- `portfolio-desktop.png`：1440×1000 使用纯演示持仓。
- `market-mobile.png`：390×844 手机行情。
- `portfolio-mobile.png`：390×844 手机持仓 CRUD。

只使用演示数据；截图前检查 URL、浏览器扩展、昵称、成本、通知和开发者工具，避免泄露真实账号或个人资产信息。README 中可用相对路径 `docs/screenshots/<name>.png` 引用。
